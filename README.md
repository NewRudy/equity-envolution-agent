# 股权估值工作台

给估值人员的可比公司工作区。每个项目依次整理标的画像、候选池、业务证据、人工判断和取价。市场法计算使用已保存、逐家核对的数据；没有可用的估值结果时仍能导出筛选底稿。

1. **标的与口径**：填写估值对象、基准日、主营、客户和商业模式，记录业务资料来源。交易案例、最近融资价格和穿透项目提供取证提示；需要按不同方法另行分析。
2. **候选池**：使用自有业务资料 CSV、OPC 历史快照或人工名单。行业标签决定检索范围，ST / 退市、非 A 股及上市月数可按项目设置。关键词只排列复核顺序；缺资料进入待核验。停牌和重组需人工查验。
3. **三态复核**：查询候选，查看模型建议、主营原文和资料来源，再填写采纳、存疑或剔除的理由。表中预填的「纳入」和模型建议都不产生人工决定。修改标的口径或重跑筛选后重新复核，旧记录仍在日志中。
4. **估值测算**：导入标的年报和可比取价，或在页面逐家补齐。支持 EV/EBITDA、P/B 和 P/E；DCF 可作为独立情景。所有金额以人民币亿元计算。可比公司需与标的使用同一年度的财务截止日，实际取价日不能晚于估值基准日。财务披露可取得性、取价方式与口径一致性由复核人员核对。
5. **结果与底稿**：导出含候选、来源、规则、人工决定、日期和计算过程的 Excel。下载项目草稿 JSON 可在总览恢复；估值确认需重新执行。项目在当前会话内可切换，刷新或关闭前请下载草稿。重跑筛选需重新选择原候选资料。

## 本地运行

Python 3.12。创建虚拟环境并安装依赖后：

```sh
python -m pip install -r requirements.txt
streamlit run app.py --server.address 127.0.0.1
python -m unittest discover -s tests -v
```

打开「合成示例」即可看到工业软件样例的入池、采纳、存疑和规则剔除。进入估值测算，生成示例底稿可得到 17.175 亿元的 EV/EBITDA 计算结果（显示 17.18）。样例公司、取价、财务和预设复核均为虚构。

### OPC 资料

在总览「导入 OPC ZIP」选择原始交付包，或将本机路径设为 `OPC_PACKAGE_PATH` 后启动。程序只把 v4 HTML 内的 JSON 和行业标签当数据读取；不运行附件脚本、不加载包内配置。原 ZIP 和样例公司的资料均未随代码分发。

交付包含 **5,576** 家 A 股资料、**20** 个归档案例。HTML 元数据标明行情快照是 **2026-10-28**，主报告期 **2026-09-30**（逐公司为准）；初筛归档日期为 **2026-11-04**。标的 17 可核对 **141 家入池 → 123 家进入模型 → 18 家建议纳入 / 105 家建议排除**。这些数字描述归档，无法证明新标的的表现。历史回放不进入真实估值；历史快照可在真实项目中提供候选线索，但不会把历史取价带入估值表，也不能用于早于快照日的筛选。

### 可选模型核对

默认可以全程离线完成。若已有获准接收业务文本的兼容模型服务，可在运行环境设置 `WORKBENCH_MODEL_ENDPOINT`、`WORKBENCH_MODEL_NAME`、`WORKBENCH_MODEL_KEY`。只在真实项目逐家点击时发送标的业务画像和该候选的业务摘录，不发送财务、项目草稿或文件。能在候选原文定位的引文才会显示；模型输出只供复核。密钥从环境读取，不进入日志、仓库或底稿。

## 市场法口径

模板要求 3–8 家有效采纳公司及合计 100% 的正权重（允许 0.05 个百分点的舍入误差，计算时归一化）。每家保存数据来源、财报截止日、实际取价日、取价依据、修正系数和理由。取价日早于基准日时在取价依据说明原因。

- EV/EBITDA：可比 EV 为市值加净债务与其他融资项目。目标 EBITDA 乘加权修正倍数，再减目标净债务。
- P/B：可比市值除以同口径账面权益。目标账面权益乘加权修正倍数。
- P/E：可比市值除以正的归母净利润或扣非归母净利润。目标净利润使用同一口径。

上述股权值再应用流动性折扣并加减其他股权调整。非零调整必须附理由和来源。样本观察区间来自选中样本的修正倍数极值。初步计算、用户填报的复核记录和模型建议均用于专业复核。

## 部署

生产服务使用原 systemd/Caddy 接口，代码目录 `/opt/equity-envolution-agent`、服务 `equity-envolution-agent.service`、子路径 `/equity_envolution/`。先备份并验证独立预览，再同步到生产。生产口令和可选模型密钥仅存服务器受限环境文件。Docker Compose 默认只绑定本机 8501 端口。
